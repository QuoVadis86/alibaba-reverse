# alibaba-reverse

阿里产品及其公开可观察接口的独立分析记录与工具。本仓库采用 Apache License 2.0 开源许可。

本项目与阿里巴巴集团及其关联公司无隶属、合作、背书或赞助关系。产品名称和商标归各自权利人所有。

## 产品目录

- [1688](1688/README.md)：MTOP 签名算法和单商品 SKU 接口客户端。

## 研究范围

- 记录公开可观察接口及获授权系统的分析结果。
- 保持分析可复现，并尽量使用必要的最小范围。
- 不提交凭据、会话数据、个人信息、保密材料或未经授权取得的数据。
