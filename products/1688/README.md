# 1688

本目录整理 1688 接口分析资料。目前包含 MTOP 请求签名算法的说明和纯本地计算实现。

## 目录

- [`docs/`](docs/)：算法说明和分析记录。
- [`tools/`](tools/)：可复用的本地分析工具。
- [`samples/`](samples/)：存放经过脱敏和审查的最小样例；目前没有原始流量样本。

## 当前内容

- [MTOP 签名算法](docs/mtop-signature.md)
- [签名计算模块](tools/mtop_sign.py)

这里仅迁入纯签名计算逻辑。该模块不发送网络请求、不获取或保存 Cookie，也不包含验证码处理逻辑。
